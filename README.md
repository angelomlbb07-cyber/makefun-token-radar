A token launch radar that ranks pre-token protocols by implied value from their own snapshot figures (TVL, 7-day growth, age with no token, category, chain count) and shows a concrete farm plan for each, in a sortable, filterable static dashboard.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
